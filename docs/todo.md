## 每阶段四步

| 步骤 | 内容 | 门控 |
| --- | --- | --- |
| A | 目标、参考、输入、预期、用例 | 参考用例可运行，本阶段依据明确 |
| B | 实现、编译和定向验证 | 编译/展开及定向测试全部通过 |
| C | 阶段测试与此前累计回归 | 必需检查全通过，无未解释差异 |
| D | 实现记录、证据、问题、结论 | 文档与代码一致，无未完成必需项 |

状态仅为未开始、进行中、未通过、通过。缺失、未执行、未知预期都不能通过。门控入口scripts/run_opna_gate.ps1，失败返回非零。阶段文档按进入顺序创建。

执行`.\scripts\run_opna_gate.ps1 -Phase N -Step D`会顺序重新执行本阶段A→B→C→D，任一步失败立即停止，成功才写入该步骤的通过证据。也可以用-Step A/B/C只运行到指定步骤。此前Phase的D必须先通过，并在当前运行中重新执行累计回归。未实现的门控直接失败。
